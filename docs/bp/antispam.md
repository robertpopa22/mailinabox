# Antispam regression prevention

### BP-MIAB-022 — Reputation evidence and reproducible policy

Shared forwarder refusal and gateway DNS interception are separate layers.
Test provider positives, negatives, ordinary DNS and actual native mail symbols.
Never equate NXDOMAIN on a positive canary, timeout or BLOCKED with a clean sender.
Require exact IP/MAC exceptions and compare remaining NAT/firewall policy.
Replay persistence without broad bypasses.

Keep logic in the edition, with private deployment bindings. Setup replay must
not reinstall obsolete budgets, thresholds or weights. Test7.99/8 boundaries,
legitimate intermediate scores, sender-brand mismatch, deduplication and backend
failure. Signed updates still need strict scope, native canaries, monotonic
revisions and last-good rollback. Retain private real-message acceptance evidence.

Directives: MIAB-01, MIAB-03, MIAB-04, MIAB-07, MIAB-08, MIAB-09.
